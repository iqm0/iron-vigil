# Skills used on this project

Third-party Agent Skills copied in unmodified, for Claude Code sessions working on this repository. Each keeps its own licence.

| Folder | Source | Licence | Why it is here |
|---|---|---|---|
| `roguelike-game-designer/` | https://github.com/hanjo92/roguelike-game-designer-skill (commit `3605336`) | MIT, as declared in its `SKILL.md` and README; the repository has no separate licence file | Run pacing, item and encounter design, balance and playtest method for survivors-likes |
| `game-feel/` | https://github.com/gamedev-skills/awesome-gamedev-agent-skills (`skills/disciplines/game-feel`) | Apache-2.0 | Feedback tiers, hit-stop and shake rules, flash limits |
| `threejs-gameplay-systems/` | https://github.com/majidmanzarpour/threejs-game-skills | MIT | Its `references/game-feel.md` and `genre-design.md`. The Three.js scaffold it describes is not used here |
| `threejs-qa-release/` | https://github.com/majidmanzarpour/threejs-game-skills | MIT | Bot playtests and headless WebGL checks |

Only the skill folders were copied: no scripts, hooks or evals.
