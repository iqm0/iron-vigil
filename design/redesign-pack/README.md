# Last Light — Agent Task Pack

Start with **MASTER_REDESIGN_BRIEF.md**. The role-specific files in `roles/` are handoff instructions for autonomous developer agents. This is a critical **redesign plan**, not an implementation of the game.

## Recommended order
1. Producer/Director agree on scope and ownership.
2. Systems, Combat and QA prototype the most consequential choices.
3. Mech, Environment and UX implement a readable vertical slice.
4. Enemy AI, Audio and WebGL engineer integrate and profile.
5. Producer runs the gate checklist before approving new content.
